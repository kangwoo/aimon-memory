# 아키텍처 결정 기록 (ADR)

명세와 계획에서 이 구현이 벗어난 자리, 그리고 왜 벗어났는지를 근거와 함께 적어 둔 곳이다. 벗어나지
않은 결정은 여기 없다 — 설계 문서가 이미 말한 것을 되풀이하지 않는다.

정본은 한국어이고, 각 문서에는 같은 이름에 `.en.md` 를 붙인 영어판이 있다. 파일 경로는 README·커밋
메시지·코드 주석이 참조하므로 바뀌지 않는다.
